# engine/core (`vp_core`)

Shared foundation of the engine: errors, UTF-8 and text normalisation, filesystem helpers, read-only memory
maps, the settings store and the `.vpoeta` project format. Static library; links `vp_third_party` (miniz,
nlohmann json) and Threads. Contracts: DESIGN.md sections 4 (normalisation), 8 (project), 9 / 9.1 (errors,
settings). Nothing here throws across the module boundary: fallible calls return `vp::Result<T>`.

## Public headers (`include/vp/`)
| Header | What |
|---|---|
| `result.h` | `Result<T>`, `Error{code, message, hint}`, `errorCodeName()` (wire names of section 9) [contract] |
| `text.h` | `decodeUtf8/appendUtf8`, `nfc`, `nfd`, `lower`, `latin_key`, `greek_key`, `greek_bare`, `en_key`, `es_key`, `es_bare`, `display_latin`; each has a `(in, std::string& out)` overload that does not allocate after warm-up |
| `fs.h` | UTF-8 paths (wide on Windows), `readFile`, `writeFileAtomic` (tmp + fsync + rename / `MoveFileExW`), `fileExists`, `fileSize`, `mtime` (Unix ms), `dataDir()`, `tempDir()`, pids and clocks |
| `mmap.h` | `MappedFile::open(path) -> Result<MappedFile>`; RAII, movable, `io` + hint on failure |
| `settings.h` | `Settings`: `load()`, `get()`, `set(patch)` (RFC 7386 merge, dotted keys accepted, atomic save) |
| `project.h` | `Project::create/open/recover/save/toZip/fromZip`, `CueRecord`, `Manifest`, lock + `checkRecovery`, `Autosaver`, `migrate` |
| `sha256.h` | streaming SHA-256 (project source hash, model file check) |

## Normalisation
`src/text.cpp` is table driven. `src/nfc_table.h` is generated by `tools/gen_nfc_table.py` from Python's
`unicodedata` (decompositions, combining classes and primary compositions for the supported ranges; lower-case
mappings, Final_Sigma classes and letter ranges for all of Unicode) and committed with it. Regenerate only when
the Python Unicode version changes, then rerun the tests. NFC/NFD cover Latin-1 Supplement, Latin Extended-A/B,
Latin Extended Additional, Greek and Coptic, Greek Extended and U+0300-036F; everything else passes through and
acts as a starter. `lower` follows Python's `str.lower` (one-to-many mappings, Final_Sigma).
Checked against `tests/fixtures/normalisation_golden.tsv` (shared with `tools/build_library/vptext.py`) and
`tests/fixtures/normalisation_core_cases.tsv` (`tools/gen_core_cases.py`).

## Project file
Zip entries in fixed order: `manifest.json`, `source.bin`, `cues.jsonl`, `glossary.json`, `corrections.json`,
`stats.json`; deflate, a timestamp every time zone renders as 2000-01-01 12:00, so a project saves to the same
bytes every time. `open()` validates the zip, CRCs, the source checksum and every JSON field (damage ->
`project_corrupt`, newer format -> `unsupported_format`, older -> `migrate()` plus a warning) and reports
`Recovery` from the lock (`name.vpoeta.lock`: pid, process start, time) and the autosave
(`name.vpoeta.autosave`). `open()` does not write the lock: the caller calls `writeLock` / `removeLock`.
`Autosaver` is pure timing (5 s debounce, 60 s cap) with an injected clock. `tools/make_project_fixtures.py`
writes the Python-made fixtures in `tests/fixtures/project/`.

`dataDir()` honours `VP_DATA_DIR` (tests, portable installs) before `%LOCALAPPDATA%` / `$XDG_DATA_HOME`.
